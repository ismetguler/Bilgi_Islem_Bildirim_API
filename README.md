## About

A backend service that powers push notifications and information delivery for university systems. Built to optimize **backend-to-mobile data flow** as part of R&D at the Erciyes University Computer Research Center (BAUM).

## Features

- 🔔 Push / notification dispatch endpoints
- 🗂️ Information-management API
- 🔌 REST architecture, mobile-client friendly
- ☁️ Firebase integration

## Tech stack

- **JavaScript / Node.js**
- **Firebase**
- **REST API**

## Run locally

```bash
git clone https://github.com/ismetguler/Bilgi_Islem_Bildirim_API.git
cd Bilgi_Islem_Bildirim_API
npm install
npm start
```
> Configure your environment variables / Firebase credentials before running.
